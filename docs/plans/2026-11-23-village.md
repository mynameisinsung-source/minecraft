# 시작 마을 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** design-village.md를 구현한다. 첫 접속 시 광장, 건물 3채, NPC 4명, 바닐라 마을을 생성하고, 대화·거래·의뢰 15개·귀환 기능을 넣는다.

**Architecture:** 기존 생성기에 모듈 5개를 추가한다.
- `tools/nbt.py`: 의존성 없는 NBT 쓰기·읽기
- `tools/structures.py`: 건물 설계 → 구조물 NBT
- `tools/content_village.py`: NPC·의뢰·거래·꾸러미 데이터
- `tools/gen_village.py`: 생성, 귀환, NPC 소환
- `tools/gen_npc.py`: 대화, 도움말
- `tools/gen_quests.py`: 의뢰 도전 과제

모든 동작은 도전 과제 트리거(첫 접속, 엔티티 우클릭, 처치, 인벤토리 변화, 마시기)로 시작한다.

**Tech Stack:** 기존과 동일. NBT는 gzip + 빅엔디언, DataVersion 3955.

**Spec:** `docs/design-village.md`

## Global Constraints
- 매 틱 함수 금지(`#minecraft:tick` 없음). `schedule`은 1회용으로만 쓴다.
- 1.21.1 문법: tellraw `clickEvent`(camelCase), 거래 `Offers.Recipes[].buy/sell = {id,count,components}`, 주민 `VillagerData:{profession,level,type}`
- 마을은 월드에 한 번만 생성한다(저장소 `create_rpg:village`의 `built`). 자동 생성은 "새 플레이어"로 보일 때만 한다(`minecraft:story/root` 미달성). 이미 진행 중인 월드는 `/function create_rpg:village/build_here`로 원하는 위치에 짓는다.
- `fill` 한 번의 부피는 32768 이하
- 건물은 모두 문이 남쪽(+z)을 향하도록 설계하고, `place template` 회전으로 방향을 맞춘다. CW90 회전은 (x,z)→(-z,x), CCW90 회전은 (x,z)→(z,-x)

## Review Focus
1. **기존 월드에 데이터팩을 추가한 경우:** 플레이어가 서 있는 기지 위에 마을이 덮어씌워지면 안 된다. → `test_auto_build_only_for_new_players`

4. **의뢰를 받기 전 기록이 집계됨** → `test_reward_resets_next_objective`
5. **시작 꾸러미 중복 수령** → `test_starter_kit_once`

### Task 10: NBT + 건물 구조물
Files: `tools/nbt.py`, `tools/structures.py`, `tests/test_structures.py`
- `nbt.write(path, root)`와 `nbt.read(path)`. 타입 래퍼는 `Int`, `Byte`, `Float`, `Double`, `String`, `List(type, items)`, `Compound(dict)`
- `Building(name, sx, sy, sz)`의 `.set(x,y,z,state)`, `.fill(x1..,state)`, `.to_structure()`. 상태 문자열 `"minecraft:oak_stairs[facing=north]"`을 palette로 변환한다.
- 건물: `forge` 9×8×9, `guild` 9×8×9, `stall` 5×5×5. 모두 local y=0이 바닥이다.
- `PLACEMENTS = {name: (dx, dz, rotation)}`: forge(-4,-12,none), guild(12,-4,clockwise_90), stall(-11,2,counterclockwise_90). y는 광장 바닥(-1)이다.
- `footprint(name) -> (xmin,xmax,zmin,zmax)`
- Tests: 다시 읽은 NBT의 DataVersion 3955, 블록 위치가 size 안에 있음, palette 이름의 네임스페이스는 minecraft/create뿐, 각 건물 남쪽 벽 가운데에 문(2칸 공기), footprint가 광장(-13..13) 안에 있고 서로 겹치지 않음

### Task 11: 마을 생성 + 귀환 + NPC 소환과 거래
Files: `tools/content_village.py`, `tools/gen_village.py`, `tests/test_village.py`
- 함수: `village/first_join`(1회성 tick 도전 과제의 보상), `village/build_here`, `village/build`(매크로로 저장된 좌표에서 `build_at` 실행), `village/build_at`, `home`, `village/home_tp`(매크로)
- `build_at`: 가드 → fill 4개(기초 돌, 바닥, 길, 공기) → place template 3개 → 종·랜턴 → NPC 4명 summon → `place structure minecraft:village_plains ~ ~ ~56`(성공 여부를 점수에 저장해서 실패 시 안내) → `setworldspawn` → `built` 기록
- NPC: `NPCS` 데이터(id, 이름, 직업, 위치, yaw, 거래). 거래 SNBT는 `items.stack_snbt(base, comps, count)` 헬퍼로 만든다(키에 콜론이 있으면 따옴표로 감싼다).
- 귀환 주문서: 효과 없는 물약, `custom_data scroll_home`, 마시면 `home`
- Tests: `test_build_guarded_once`, `test_auto_build_only_for_new_players`, `test_fill_volumes_within_limit`, `test_npcs_stand_in_air_inside_their_building`, `test_four_npcs_summoned_with_tags_and_noai`, `test_trades_buy_rpg_items_by_custom_data`, `test_home_macro_and_return_scroll`

### Task 12: NPC 대화 + 촌장 도움말 + 시작 꾸러미
Files: `tools/gen_npc.py`, `tests/test_npc.py`
- 도전 과제 `npc/talk_<id>`(트리거 `player_interacted_with_entity`, 태그 `rpg_npc_<id>`) → 함수 `npc/<id>/talk`. 첫 줄은 도전 과제 해제.
- 촌장: 태그 `rpg_started`가 없으면 소개 + 꾸러미 + `advancement grant @s only create_rpg:quest/root` + `scoreboard players set @s q01 0` + 태그 추가. 태그가 있으면 도움말 메뉴(주제 8개, clickEvent `/function create_rpg:npc/chief/help/<topic>`)
- "지금 뭘 해야 하지?": 아직 완료하지 않은 첫 의뢰의 힌트를 출력
- 대장장이·의뢰소장·상인: 진행에 따른 대사. 의뢰소장은 현재 의뢰와 점수(score 컴포넌트)를 보여 준다.
- Tests: `test_talk_advancements_revoke_and_exist`, `test_starter_kit_once`, `test_help_topics_clickable`, `test_whats_next_covers_all_quests`

### Task 13: 의뢰 15개
Files: `tools/gen_quests.py`, `tests/test_quests.py`, `tools/gen_enhance.py`(load 함수에 objective 추가)
- 도전 과제 `quest/root`(트리거 impossible, 탭 배경), `quest/q01..q15`. 각 의뢰는 이전 의뢰 달성을 조건으로 한다(player 술어의 advancements).
- 집계 조건은 `minecraft:entity_scores`다. 트리거는 처치 의뢰가 `player_killed_entity`, 줍기·제작·장비 의뢰가 `inventory_changed`다. 장비 의뢰는 forge 도전 과제 달성을 조건으로 한다.
- 보상 함수: 보상 지급 + 완료 메시지 + 다음 objective 0으로 초기화
- Tests: `test_fifteen_quests_chained`, `test_objectives_created_on_load`, `test_reward_resets_next_objective`, `test_quest_rewards_valid_items`
