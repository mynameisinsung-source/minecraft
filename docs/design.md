# Create RPG 데이터팩 — 설계 문서

작성일: 2026-11-23

## 1. 의도
- 혼자서 **약 일주일** 즐길 Create + RPG 플레이.
- 사냥·광질로 **생활 레벨**을 올리고, 얻은 재료를 **Create 공장(대장간)**에서 가공해 장비를 만든다. 두 가지가 서로 맞물려 순환한다.
- 서버는 **Aternos**(무료, 메모리 적음). 직접 만든 .jar는 올릴 수 없고, **데이터팩은 올릴 수 있다.**

## 2. 목표 / 비목표 / 반목표
**목표**
- 순환 구조: 레벨 → 상위 재료 → Create 공정 → 장비 → 더 높은 레벨
- 스킬트리 3개: 사냥, 광질, 대장장이
- 장비 5단계, 하루 1단계 안팎의 속도 (일주일 분량)
- 최종 목표: 전설 장비를 완성해 위더와 엔더 드래곤을 처치

**비목표**
- 새 블록, 새 기계, 새 화면, 새 텍스처 (v1에서는 리소스팩 없음, 바닐라 아이템에 이름·설명·능력치를 붙여 사용)
- 멀티플레이 밸런스

**반목표** (돌아가더라도 실패로 보는 것)
- Aternos 서버를 느리게 만드는 것: **매 틱 도는 함수 금지**
- Create 없이도 진행할 수 있는 것: 상위 장비는 반드시 Create 공정을 거쳐야 함
- 일주일 안에 끝낼 수 없을 만큼 반복 작업이 많은 것

## 3. 제약 / 구성
| 항목 | 선택 |
|---|---|
| 버전 | Minecraft 1.21.1, NeoForge |
| Aternos에서 설치하는 모드 | Create 6.0.x (6.0.3 이상), Pufferfish's Skills. Pufferfish's Attributes는 설치해도 되지만 v1은 바닐라 능력치만 사용 |
| 직접 만드는 것 | 데이터팩 `create_rpg` (zip) + Aternos 설치 안내서 |

## 4. 접근 방식
- **A. 데이터팩만 사용**: 가볍지만 스킬트리 화면이 없음.
- **B. 데이터팩 + 데이터로 설정하는 스킬 모드** ← **선택**. 스킬트리 화면이 생기고, 내용은 데이터팩으로 직접 짠다. 혼자 오래 키우는 플레이에 성장하는 재미를 준다.
- **C. 직접 만든 모드**: Aternos에 올릴 때마다 공개 등록과 심사가 필요해서 제외.

## 5. 설계

### 5.1 스킬트리 (Pufferfish's Skills, 데이터팩으로 정의)
| 트리 | 경험치를 얻는 방법 | 주요 보상 |
|---|---|---|
| 사냥 | 몬스터 처치 (최대 체력에 비례) | 공격력, 체력, 치명타 계열 능력치, 상위 드롭 해금 태그 |
| 광질 | 블록 채굴 (광석 > 돌, 깊은 광석일수록 높음) | 채굴 속도, 광석 추가 드롭 계열 능력치, 상위 광맥 재료 해금 태그 |
| 대장장이 | Create 부품 제작 + 각 장비 첫 완성 (도전 과제 보상 함수가 경험치 지급) | 방어력, 방어 강도, 공격 속도 능력치, 보너스 재료 지급 |

- 대장장이 경험치: (1) Create 부품(톱니바퀴, 케이싱, 기계 등)을 제작대에서 만들 때 `puffish_skills:craft_item`으로 지급. (2) 장비 30종 각각을 **처음** 손에 넣을 때 도전 과제(`inventory_changed`, 1회성)의 보상 함수가 `puffish_skills experience add`를 실행. 1회성이라 인벤토리를 뒤섞어 경험치를 무한히 얻을 수 없다. 둘 다 이벤트가 생길 때만 실행되므로 틱 부하가 없다.
- **레벨로 해금하기**: 스킬 노드 보상으로 플레이어에게 태그(예: `rpg_hunt_3`)를 붙인다. 몬스터 드롭 테이블은 처치한 플레이어의 태그를 조건으로 검사해서 상위 재료를 떨어뜨린다.

### 5.2 재료
바닐라 아이템에 `custom_name`, `lore`, `custom_data`를 붙인 RPG 재료를 쓴다.
- 드롭 추가는 바닐라 드롭 테이블을 덮어쓰지 않고 NeoForge 전역 루트 수정자(`neoforge:add_table`)로 한다. Create 등 다른 모드의 드롭과 충돌하지 않는다.
- **몬스터 정수** (단계별): 몬스터 드롭 테이블에 추가. 상위 정수는 강한 몬스터(네더·엔드)가 떨어뜨리고, 사냥 레벨 태그가 있어야 나온다.
- **광맥 조각** (단계별): 광석 채굴 드롭에 추가. 광질 레벨 태그가 있어야 나온다. (태그 조건이 블록 드롭 테이블에서 동작하지 않으면 Create 분쇄 레시피의 추가 산물로 대체한다.)
- 원재료를 Create 기계(분쇄·혼합·압착)에 넣으면 **강화 가루 / 합금 판** 같은 중간재가 된다.

### 5.3 장비 5단계 (하루 안팎에 1단계)
| 단계 | 이름(가칭) | 필요한 Create 기술 | 필요한 레벨 재료 |
|---|---|---|---|
| 1 | 구리 견습 | 수동 압착, 분쇄 | 없음 |
| 2 | 황동 숙련 | 혼합기, 황동 | 정수 1, 광맥 1 |
| 3 | 강철 장인 | 조립 라인(sequenced assembly) 입문 | 정수 2, 광맥 2 (네더) |
| 4 | 비전 명장 | 긴 조립 라인 + 액체 주입 | 정수 3, 광맥 3 |
| 5 | 전설 | 여러 공정을 잇는 공장 | 정수 4 (엔드), 위더 별 |

- 무기, 방어구, 도구 모두 `attribute_modifiers`, 인챈트, 이름, 설명을 붙인 바닐라 장비로 만든다.
- 상위 장비의 마지막 공정은 반드시 Create 조립 라인(sequenced assembly)을 거친다.

## 7. 빌더에게 맡기는 것
- 정확한 수치 (경험치 곡선, 능력치 값, 드롭 확률). 일주일 분량에 맞춰 정하고 표로 남긴다.
- 아이템 이름과 설명 문구 (한국어)
- 테스트: JSON 문법을 검증하는 스크립트. 실제 동작은 사용자가 Aternos 서버에서 확인하며, 단계별 확인 체크리스트를 제공한다.
